  1. Manuscript
    MemSIF: From Structured Interactions to Dual-Track Fact Memory for LLM Agents
    Yufei Luo, Zhen Yang, and others
    Preprint link and complete author list forthcoming. , 2026
    Manuscript
    Abs Bib

    Long-term memory is critical for LLM agents in long-horizon interactions, yet real interaction histories exhibit Temporal–Structural Misalignment and Delayed Utility Manifestation. MemSIF organizes raw interactions into Structured Interaction Memory and combines CoreFact for stable fact consolidation with ActiveFact for query-driven dynamic fact activation.
